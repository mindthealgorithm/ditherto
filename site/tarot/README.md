# Tarot studies

Five original PNGs supplied by Jessey White-Cinis for the ditherto examples: The Fool, The Magician, The High Priestess, The Empress, and The Emperor. The supplied filenames and original pixels are preserved. The website processes these originals live.

These artworks are separate from the MIT-licensed library code; this file grants no additional artwork license. They are not included in the npm package.
