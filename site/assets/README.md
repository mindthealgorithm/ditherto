# Image credits

The static README/social previews are lossless PNGs generated by `scripts/generate-site-assets.mjs` using ditherto itself. The homepage instead uses the original photographs with `observeDitherDOM`, rerendering each tile at its display width when the layout changes. Its shared worker keeps processing off the main thread.

Coffee: Rachel Michetti, CC0. Chelsea the cat: Stefan van der Walt, CC0. Eileen Collins portrait: NASA, public domain. Source files and pinned checksums are in [the photographic corpus](https://github.com/jcinis/ditherto/blob/main/tests/fixtures/photos/README.md). No generated or simulated dither results are used.
